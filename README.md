# ميزانيتي — إدارة الميزانية الشخصية

تطبيق لتتبّع الدخل والمصروفات والأهداف المالية بعملتين (افتراضياً ريال سعودي وجنيه مصري). يعمل على الكمبيوتر والموبايل، **وبدون إنترنت**، ويتزامن تلقائياً بين أجهزتك عند تسجيل الدخول بحساب Google.

- 🌐 نسخة الويب: https://refaatahmed374-ui.github.io/myzanetty/
- 📱 تطبيق أندرويد: [آخر إصدار (APK)](https://github.com/refaatahmed374-ui/myzanetty/releases/latest) — ويتحدث بعدها من داخل التطبيق

## المميزات

- **لوحة تحكم**: إيرادات، مصروفات، صافي، معدل ادخار، أرصدة الحسابات، ورسوم بيانية لكل شهر وتوزيع المصروفات.
- **العمليات**: إضافة/تعديل/حذف، بحث وفلترة، تجميع حسب الشهر، **نسخ عمليات شهر**، وإكمال تلقائي للبيان والمبلغ.
- **العمليات المتكررة**: الراتب والإيجار والاشتراكات تتسجل تلقائياً كل شهر في يومها، بمبلغ ثابت بأي من العملتين.
- **الأقساط والديون**: المدفوع والمتبقي وعدد الأقساط الباقية وتاريخ الانتهاء المتوقع، مع تسجيل دفعات يدوي أو تلقائي.
- **الحسابات والمحافظ**: بنك، كاش، محفظة إلكترونية… لكل منها عملة ورصيد، مع **تحويل بين الحسابات** (لا يُحسب إيراداً ولا مصروفاً).
- **التقارير**: شهري، حسب الفئة، مقارنة شهرين، تدفق نقدي تراكمي، توقعات لبقية السنة، و**تقرير PDF** شهري أو سنوي.
- **تحليل ذكي** (على الجهاز بالكامل): الفئات مقارنة بمتوسط آخر 3 أشهر، المصروفات غير المعتادة، البنود المتكررة، توقع مصروف الشهر، وفرص التوفير.
- **الأهداف المالية**: تقدم الهدف والمبلغ المطلوب شهرياً للوصول إليه في موعده.
- **ميزانية لكل فئة** مع تنبيه فوري عند الوصول لـ 80% أو تجاوز الحد.
- **سعر الصرف تلقائياً** من الإنترنت (ExchangeRate-API) كل 12 ساعة، أو يدوياً.
- **إشعارات أندرويد**: تذكير يومي بتسجيل المصروفات، وتذكير قبل مواعيد الأقساط والالتزامات بيوم.
- **ودجت للشاشة الرئيسية** في أندرويد: صافي الشهر والإيرادات والمصروفات وزر إضافة سريع.
- **قفل التطبيق** برمز PIN، مع **الفتح بالبصمة أو الوجه** على أندرويد.
- **نسخ احتياطي**: تصدير/استيراد JSON (يشمل كل البيانات)، وتصدير/استيراد CSV (يفتح في Excel).
- وضع داكن، أرقام غربية (123) في كل التطبيق، وواجهة عربية بالكامل (RTL).

## التثبيت على الموبايل

### الطريقة 1: تثبيت نسخة الويب (الأسرع)
افتح رابط الموقع في **Chrome** على الموبايل ← القائمة (⋮) ← **تثبيت التطبيق / Add to Home screen**. سيظهر كأيقونة ويعمل بدون إنترنت.

### الطريقة 2: ملف APK (تطبيق أندرويد كامل)
1. افتح من الموبايل: [آخر إصدار](https://github.com/refaatahmed374-ui/myzanetty/releases/latest) ← نزّل ملف `myzanetty-X.Y.Z.apk`.
2. افتحه واسمح بالتثبيت من مصادر غير معروفة.
3. **التحديثات بعد كده من داخل التطبيق:** الإعدادات ← حول التطبيق ← **التحقق من التحديثات** (أو البانر اللي بيظهر لوحده).

### الودجت والإشعارات (أندرويد)
- **الودجت**: اضغط مطولاً على مكان فاضي في الشاشة الرئيسية ← **الأدوات / Widgets** ← **ميزانيتي** واسحبه للشاشة.
- **الإشعارات**: من الإعدادات ← الإشعارات والتذكيرات، ووافق على إذن الإشعارات أول مرة.
- **البصمة**: الإعدادات ← **الدخول بالبصمة** ← تفعيل (لا يحتاج رمز PIN، والبديل رمز قفل الموبايل).

## إعداد لمرة واحدة

### 1) قواعد أمان Firestore (مهم جداً)
Firebase Console ← Firestore Database ← **Rules** ← الصق محتوى [firestore.rules](firestore.rules) ← **Publish**.
هذه القواعد تضمن أن كل مستخدم يقرأ ويكتب بياناته فقط.

### 2) GitHub Pages
Settings ← Pages ← Source: **GitHub Actions**. بعدها كل push على `main` ينشر النسخة الجديدة تلقائياً.

### 3) أسرار توقيع APK
مفتاح التوقيع موجود محلياً في مجلد `keys/` (غير مرفوع على GitHub). أضف في Settings ← Secrets and variables ← Actions:

| الاسم | القيمة |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | محتوى `keys/myzanetty-release.p12` بصيغة base64 |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة المرور من `keys/KEYSTORE-INFO.txt` |

بدون هذه الأسرار يُبنى APK بنسخة debug (يعمل، لكن تسجيل الدخول بـ Google لن يعمل عليه).
> ⚠️ احتفظ بنسخة من مجلد `keys/` في مكان آمن. لو ضاع المفتاح لن تستطيع تحديث التطبيق المثبت، وستحتاج لحذفه وتثبيته من جديد.

### 4) تسجيل الدخول بـ Google داخل تطبيق أندرويد
(نسخة الويب لا تحتاج هذه الخطوة.)
1. **Web client ID**: Firebase Console ← Authentication ← Sign-in method ← Google ← **Web SDK configuration** ← انسخ *Web client ID* وضعه في `GOOGLE_WEB_CLIENT_ID` داخل [src/config.js](src/config.js).
2. **عميل Android**: [Google Cloud Console](https://console.cloud.google.com/apis/credentials?project=myzanetty-2026) ← Create credentials ← **OAuth client ID** ← نوع **Android**:
   - Package name: `com.myzanetty.app`
   - SHA-1: من ملف `keys/KEYSTORE-INFO.txt`

## نقل البيانات من النسخة القديمة
- **تلقائي**: عند تسجيل الدخول بنفس حساب Google، تُنقل بياناتك المحفوظة في السحابة من النسخة القديمة إلى النظام الجديد مرة واحدة. الحقل القديم يبقى في Firebase كنسخة احتياطية.
- **يدوي**: الإعدادات ← استيراد نسخة احتياطية ← اختر ملف `backup/legacy-data.json`. الملف موجود على جهازك فقط وليس على GitHub. يمكن استيراده أكثر من مرة دون تكرار العمليات.

## التطوير

```bash
npm install
npm run dev        # تشغيل محلي على http://localhost:5173
npm test           # اختبارات الحسابات والاستيراد والمتكرر والأقساط
npm run build      # بناء نسخة الإنتاج في dist/
npm run icons      # إعادة توليد الأيقونات من public/icon.svg
npm run android:sync   # بناء + نسخ الملفات لمشروع أندرويد
```

ملف APK يُبنى على GitHub Actions (لا يحتاج Android Studio). لبنائه محلياً تحتاج JDK 21 + Android SDK ثم: `cd android && ./gradlew assembleDebug`.

الهيكل الكامل للملفات وبنية البيانات في Firestore وكيف تتصل الأجزاء ببعض: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## الخصوصية
- لا توجد أي بيانات شخصية داخل الكود.
- عند تسجيل الدخول تُحفظ البيانات في حسابك على Firebase، وقواعد Firestore تمنع أي مستخدم آخر من قراءتها.
- مفتاح Firebase الظاهر في الكود عادي لتطبيقات الويب ولا يمنح أي صلاحية بمفرده.
- عند تسجيل الخروج تُمسح نسخة البيانات المخزنة على الجهاز.
- المستودع عام عن قصد (GitHub Pages مجاني + التحديث من داخل التطبيق يقرأ صفحة الإصدارات العامة)، ولا يحتوي أي بيانات أو أسرار — التفاصيل في [خريطة المشروع](docs/ARCHITECTURE.md#8-الأمان-والخصوصية).
