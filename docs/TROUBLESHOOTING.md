# دليل الإصلاح — لو حاجة باظت

> لكل مشكلة: **العَرَض ← السبب ← الحل**. لو المشكلة مش هنا، ابدأ من [قسم التشخيص العام](#التشخيص-العام) في الآخر.
> لفهم أجزاء التطبيق، انظر [خريطة المشروع](ARCHITECTURE.md).

## 🔐 الحساب والمزامنة

### علامة المزامنة فوق مكتوب فيها "خطأ" باللون الأحمر
- **السبب الأشهر:** قواعد Firestore لا تسمح بالكتابة في المجموعات الفرعية.
- **الحل:** Firebase Console ← Firestore Database ← **Rules** ← الصق محتوى [`firestore.rules`](../firestore.rules) كاملاً ← **Publish**. تأكد إن فيه سطر `match /{document=**}` **داخل** `match /users/{uid}`.
- **للتأكد:** في المتصفح على الكمبيوتر افتح أدوات المطور (F12) ← Console، لو ظهر `permission-denied` فهي القواعد.

### "غير متصل" ولا تتزامن
- طبيعي بدون إنترنت — كل شيء يُحفظ على الجهاز ويُرفع لوحده لما يرجع النت. لا تسجّل خروج وانت غير متصل (الخروج يمسح النسخة المحلية).

### تسجيل الدخول بـ Google لا يعمل في **تطبيق أندرويد**
| الرسالة | السبب | الحل |
|---|---|---|
| "تسجيل الدخول على أندرويد غير مُعدّ بعد" | `GOOGLE_WEB_CLIENT_ID` فاضي في `src/config.js` | ضع Web client ID (Firebase Console ← Authentication ← Sign-in method ← Google ← Web SDK configuration) ثم أصدر نسخة جديدة |
| خطأ عام / "No credentials available" / "developer error" | عميل OAuth الأندرويد غير موجود أو SHA-1 خطأ | [Google Cloud ← Credentials](https://console.cloud.google.com/apis/credentials?project=myzanetty-2026) ← تأكد من عميل **Android** باسم الحزمة `com.myzanetty.app` و SHA-1 الموجود في `keys/KEYSTORE-INFO.txt` |
| يعمل على APK الإصدار ولا يعمل على نسخة debug | نسخة debug موقّعة بمفتاح مختلف | استخدم APK من Releases (موقّع بمفتاح الإصدار) |

### تسجيل الدخول لا يعمل في **الموقع**
- `auth/unauthorized-domain` ← Firebase Console ← Authentication ← Settings ← **Authorized domains** ← أضف النطاق.
- النافذة المنبثقة محجوبة ← التطبيق يحوّل تلقائياً لطريقة إعادة التوجيه؛ اسمح بالنوافذ المنبثقة للموقع.

### بياناتي القديمة لم تظهر بعد تسجيل الدخول
1. تأكد إنك دخلت **بنفس حساب Google** القديم.
2. لو لسه: الإعدادات ← **استيراد نسخة احتياطية** ← اختر `backup/legacy-data.json` (على جهاز الكمبيوتر). الاستيراد آمن ويمكن تكراره بدون ما تتكرر العمليات.
3. النسخة القديمة محفوظة أيضاً في Firestore في المستند `users/{uid}` (حقل `DATA`) ولم تُحذف.

## 📱 تطبيق أندرويد

### البصمة: "جاري فحص البصمة…" لا تنتهي / لا شيء يحدث
- **أُصلحت في 2.3.1.** السبب كان انتظار كائن الإضافة نفسه بـ `await` (انظر "القاعدة الذهبية" في [ARCHITECTURE.md](ARCHITECTURE.md#7-ميزات-أندرويد-الأصلية)). لو ظهرت مرة أخرى بعد تعديل جديد فابحث في الكود عن دالة `async` ترجع إضافة Capacitor.
- لو ظهرت رسالة سبب تحت الزر:
  - "لا توجد بصمة مسجّلة" ← سجّل بصمة من إعدادات الموبايل ← الأمان.
  - "الموبايل لا يدعم البصمة لهذا التطبيق" ← بعض الأجهزة (وجه فقط / بصمة "ضعيفة")؛ التفعيل يعمل برمز قفل الموبايل بدلاً منها.

### نسيت رمز PIN أو البصمة لا تفتح
- شاشة القفل بالبصمة فيها دائماً بديل **رمز/نمط قفل الموبايل**.
- شاشة PIN فيها زر **نسيت؟**: لو مسجّل دخول ← يسجّل خروج ويلغي القفل (البيانات آمنة في السحابة). لو محلي فقط ← يحذف بيانات الجهاز (لذلك صدّر نسخة احتياطية دورياً).

### الإشعارات لا تصل
1. الإعدادات ← الإشعارات والتذكيرات ← فعّل ووافق على الإذن.
2. إعدادات الموبايل ← التطبيقات ← ميزانيتي ← الإشعارات ← مسموحة. وفي **البطارية** ← اختر "غير مقيّد" (بعض الشركات مثل شاومي وسامسونج توقف التنبيهات المجدولة لتوفير البطارية).
3. تذكيرات الأقساط تظهر فقط لو فيه أقساط أو عمليات متكررة (مصروفات) مفعّلة.

### الودجت لا يتحدث أو يقول "افتح التطبيق للتحديث"
- الودجت يأخذ بياناته من التطبيق: افتح التطبيق مرة بعد أي تغيير. يتحدث أيضاً كل 30 دقيقة تلقائياً بآخر بيانات وصلته.

### التحديث من داخل التطبيق لا يعمل
| العرض | الحل |
|---|---|
| "محاولات كثيرة، جرّب بعد شوية" | حد GitHub للطلبات (60 في الساعة)؛ انتظر ساعة |
| يطلب إذن "تثبيت تطبيقات غير معروفة" كل مرة | فعّله من إعدادات الموبايل لتطبيق ميزانيتي |
| "تعذر التحديث" | استخدم زر "تنزيل من المتصفح" الظاهر تحت الرسالة، أو حمّل APK من صفحة Releases |
| أندرويد يقول "التطبيق غير مثبّت / تعارض" | الـ APK الجديد موقّع بمفتاح مختلف (مثلاً debug) — احذف التطبيق القديم وثبّت الجديد بعد تصدير نسخة احتياطية |

### "التطبيق غير مثبّت" عند تثبيت APK من Releases
- نفس السبب: اختلاف مفتاح التوقيع أو رقم إصدار أقدم. صدّر نسخة احتياطية ← احذف التطبيق ← ثبّت.

## 💱 الأرقام والعملات

### سعر الصرف تغيّر لوحده
- "تحديث سعر الصرف تلقائياً" مفعّل (يجيب السعر الرسمي كل 12 ساعة). لو بتحوّل بسعر مختلف: الإعدادات ← العملات ← ألغِ التحديث التلقائي واكتب السعر. العمليات المسجلة سابقاً **لا تتغير** — كل عملية تحفظ سعرها.

### العمليات المتكررة لم تُضف
- القاعدة تبدأ من شهر البداية (الافتراضي الشهر القادم)، وتُضاف في يومها أو بعده عند فتح التطبيق.
- تأكد إنها **مفعّلة** (العمليات ← المتكررة).
- لو حذفت عملية متكررة مُنشأة، لن تُعاد (هذا مقصود).
- قسط مرتبط بدفع تلقائي يتوقف عند اكتمال المبلغ.

### أرصدة الحسابات غريبة
- راجع **الرصيد الافتتاحي** للحساب (الإعدادات ← الحسابات) — يُفترض أنه الرصيد قبل أول عملية مسجلة.
- العمليات القديمة بدون حساب تُحسب على الحساب الأول.

## 🌐 الموقع (GitHub Pages)

### الموقع لم يتحدث بعد push
1. GitHub ← **Actions** ← "Deploy web app" ← تأكد إنه نجح (✓). لو فشل افتحه واقرأ الخطوة الحمراء — غالباً اختبار فشل (`npm test`).
2. التطبيق المثبّت من المتصفح يعرض بانر "يتوفر إصدار جديد" ← اضغط تحديث. أو الإعدادات ← التحقق من التحديثات.
3. Settings ← Pages ← Source لازم يكون **GitHub Actions**.

## 🏗️ مشاكل البناء (للمطوّر)

| المشكلة | السبب | الحل |
|---|---|---|
| `keystore password was incorrect` في Actions | سر `ANDROID_KEYSTORE_PASSWORD` ناقص حرف أو فيه مسافة | من مجلد المشروع في PowerShell: `(Select-String -Path "keys\KEYSTORE-INFO.txt" -Pattern '[0-9a-f]{32}' -CaseSensitive).Matches[0].Value \| gh secret set ANDROID_KEYSTORE_PASSWORD -R refaatahmed374-ui/myzanetty` |
| `Value is null` في `build.gradle` | صيغة Groovy لقراءة متغيرات البيئة | اقرأ المتغيرات في `def` أعلى الملف (كما هو حالياً) |
| بعد `npm install` تغيّر `gradle-wrapper.properties` لإصدار 9.x | بعض المكتبات تحدّثه | ارجعه: `git checkout -- android/gradle/wrapper/gradle-wrapper.properties` (المعتمد 8.14.3) |
| خطأ Java في `BudgetWidget` أو `AppUpdaterPlugin` | تعديل في `android/app/src/main/java/...` | البناء يتم على GitHub فقط (لا يوجد Android SDK محلياً) — اقرأ سجل الخطوة "بناء APK" في Actions |
| إضافة Capacitor جديدة لا تعمل على الموبايل | لم يُنفّذ `cap sync` أو الإضافة تُنتظر بـ `await` | `npx cap sync android`، وراجع القاعدة الذهبية |
| أوامر Git Bash تحوّل `#/reports` أو `/CN=` لمسار ويندوز | تحويل المسارات في MSYS | ابدأ الأمر بـ `MSYS_NO_PATHCONV=1` |

## التشخيص العام

1. **أي إصدار عندي؟** الإعدادات ← حول التطبيق ← الإصدار. قارنه بآخر إصدار في [Releases](https://github.com/refaatahmed374-ui/myzanetty/releases).
2. **هل البيانات سليمة؟** الإعدادات ← تصدير نسخة احتياطية — احتفظ بها قبل أي إصلاح.
3. **رسائل الخطأ في الموقع:** على الكمبيوتر F12 ← Console.
4. **رسائل الخطأ في أندرويد:** نسخة الإصدار تمنع فحص الصفحة لأسباب أمنية. للتشخيص مؤقتاً: أضف `"webContentsDebuggingEnabled": true` داخل `"android"` في `capacitor.config.json` وأصدر نسخة، ثم وصّل الموبايل بالكمبيوتر (مع تفعيل "تصحيح أخطاء USB") وافتح `chrome://inspect` في Chrome ← ميزانيتي ← Console. **أرجع الإعداد لـ false بعد الانتهاء.**
5. **الاختبارات:** `npm test` — لازم كلها `ok`. أضف اختباراً لأي خطأ تصلحه في `tests/core.test.mjs`.
6. **تشغيل محلي:** `npm install` ثم `npm run dev` ← `http://localhost:5173`.
